# ☕ Western Cafe Performance Dashboard

## 📌 Project Overview

The **Western Cafe Performance Dashboard** is an **end-to-end Data
Analytics project** that transforms raw café sales data into meaningful
business insights using **Microsoft Excel, PostgreSQL, SQL, and Power
BI**.

This project demonstrates the complete analytics workflow---from **data
cleaning and transformation** to **business analysis**, **KPI
development**, and **interactive dashboard creation**.

------------------------------------------------------------------------

## 🎯 Objectives

-   Clean and prepare raw sales data.
-   Analyze business performance using SQL.
-   Build meaningful KPIs.
-   Create an interactive Power BI dashboard.
-   Generate actionable business insights.

## 📌 Key Business Insights

-   Generated **\$89.1K** in revenue across **10K** customer
    transactions.
-   Sold **28.8K** products with an average order value of **\$8.91**.
-   **Cash** accounted for **54.12%** of total revenue.
-   **Other** store locations generated the highest revenue.
-   Revenue peaked in **June** and **October**.
-   **Salad, Sandwich, and Smoothie** were the top revenue-generating
    products.
